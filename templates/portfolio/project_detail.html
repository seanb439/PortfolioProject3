Project 1: Handwritten Digit Classification with K-Nearest Neighbors

Objective: Build a machine learning model capable of recognizing handwritten digits using the K-Nearest Neighbors classification algorithm.

Dataset: The project uses the handwritten digits dataset from Scikit-learn through load_digits(). The dataset contains images of handwritten numbers (0-9) represented as 8×8 pixel arrays.

Development Process: The dataset was loaded and explored by reviewing descriptions, feature values, target labels, and dataset dimensions. Matplotlib was used to visualize sample digits and verify the image structure. The data was split with train_test_split(), a K-Nearest Neighbors classifier was trained, and predictions were generated for the test set.

Model Evaluation: Accuracy scoring, prediction comparison, error analysis, and confusion matrix generation were used to assess performance. A Seaborn heatmap made the classification results easy to interpret.

Project 2: California Housing Price Prediction with Linear Regression

Objective: Predict California housing prices using linear regression based on demographic and geographic housing features.

Dataset: The project uses the California Housing dataset from Scikit-learn through fetch_california_housing(). The dataset includes variables such as median income, house age, average rooms, population, latitude, and longitude.

Development Process: The dataset was loaded into a Pandas DataFrame, descriptive statistics were generated, and a random sample was created for exploratory analysis. The data was then divided into training and testing sets, and a linear regression model was trained using the training data.

Prediction and Visualization: The model generated housing price predictions for the testing dataset, and a scatterplot with a diagonal reference line was used to compare actual versus predicted values. Points closer to the line indicated more accurate predictions.
